## [0.1.0] - 2026-10-17

### Added

- `request-ai-export` skill: writes a short text and a copy-paste prompt that gets a friend's AI to find, redact, zip and send their skills, plugins, rules and notes on a topic, with a copy-paste fallback for chat-only AIs.
- Checklist for safely receiving a kit: own folder, run nothing, read for injected instructions and secrets, vet before install.
- Claude Code plugin and marketplace manifests, Codex plugin manifest.
- Worked example for Roblox game dev and 7 structural tests run in CI.
