launch-poof

A skill-sharing plugin for Claude Code and Codex. Your agent writes one text and one prompt; your friend's AI finds their skills, plugins, rules and notes on a topic, redacts secrets, zips them and tells them how to send the kit.

View on GitHubSee an example

Install

claude plugin marketplace add deserteaglemj/launch-poof
claude plugin install launch-poof@launch-poof

Codex: codex plugin marketplace add deserteaglemj/launch-poof. Other tools: copy skills/request-ai-export/ into the tool's skills folder.

What the friend does

Paste one prompt, say "yes", drag a zip into your chat. Chat-only AIs give one copy-paste block instead.

Proof

7 structural tests pass (results). How well a given friend's AI follows the prompt has not been measured yet.

FAQ

Does it send my data anywhere?
No. The skill only writes text for you to send. The friend's AI makes a local zip, and the friend chooses how to send it.
Is it safe to install skills someone sends me?
Only after checking. The skill unzips the kit into its own folder, runs nothing, and vets each skill before any install.
Does it work with Cursor, Windsurf or Gemini CLI?
Yes, the prompt names their folders. Chat-only AIs get a copy-paste fallback.
