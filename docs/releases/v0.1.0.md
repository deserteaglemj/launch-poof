# launch-poof v0.1.0

First public release.

## Highlights

- One skill, `request-ai-export`: your agent writes a short text and a copy-paste prompt; your friend's AI finds their skills, plugins, rules, MCP setup and notes on a topic, replaces secrets with `[REDACTED]`, waits for one "yes", zips the kit and tells them how to send it.
- Works with Claude Code, Codex, Cursor, Windsurf and Gemini CLI folders; chat-only AIs (ChatGPT, claude.ai) output one copy-paste block instead.
- A receiving checklist: unzip into its own folder, run nothing, read for injected instructions and leftover secrets, vet before installing.

## Install

```bash
claude plugin marketplace add deserteaglemj/launch-poof
```

```bash
claude plugin install launch-poof@launch-poof
```

Codex: `codex plugin marketplace add deserteaglemj/launch-poof`. Other tools: copy `skills/request-ai-export/` into the tool's skills folder.

## Proof

7 of 7 structural tests pass and `claude plugin validate --strict .` passes ([evals/RESULTS.md](https://github.com/deserteaglemj/launch-poof/blob/main/evals/RESULTS.md)).

## Known limitations

- Results depend on the friend's AI; no end-to-end runs across tools have been measured.
- Redaction is best effort by the friend's AI; treat every kit as untrusted.
- Delivery is manual (chat, AirDrop or email; Gmail caps attachments at 25 MB).
